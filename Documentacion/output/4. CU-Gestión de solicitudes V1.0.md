- 1. Introducción. un sistema de turnos es una herramienta clave para la gestión eficiente del tiempo y los recursos humanos en cualquier organización, ayudando a garantizar un flujo de trabajo ordenado y productivo.
- 2. Objetivo. Este caso de uso permite una gestión eficiente de las solicitudes de cambio de turno, solicitudes de Licencias y vacaciones, brindando al administrador la capacidad de tomar decisiones rápidas y comunicarse claramente con los empleados sobre el estado de sus solicitudes.
- 3. Definición Caso de Uso 3.1. Actores


- 1. Administrador del área
- 2. Sistema
- 3.2. Precondiciones


- 1. Que el administrador cuente con el Rol: AdminArea.
- 2. Que los empleados hayan enviado solicitudes con el estado pendiente aprobar turno.
- 3. Que las solicitudes por licencias/vacaciones enviadas por el empleado cuenten con el estado pendiente de Aprobar.


### 3.3. Flujo Normal Básico

- 1. El administrador ingresa su usuario y contraseña e inicia sesión.
- 2. El sistema valida que las credenciales sean correctas. FA01
- 3. El administrador ingresa al módulo de gestión de solicitudes.
- 4. El sistema muestra en pantalla las opciones siguientes:AN05

- a. Solicitudes Cambio de Turno
- b. Solicitudes Licencias y Vacaciones


- 5. El administrador selecciona la opción Solicitudes Cambio de turno. FA03 RN01
- 6. El sistema muestra en pantalla una lista de todas las solicitudes de cambio de turno. AN06
- 7. Para cada solicitud, el administrador tiene las siguientes Opciones:


- a. Aprobar.
- b. Rechazar


#### c. Botón “Guardar”

- 8. El administrador selecciona la opción Aprobar. FA02, FA05, RN01, RN02

- 9. El sistema valida que la solicitud no esté siendo procesada por otro administrador
- 10. El sistema aprueba el cambio de turno y cambia de estado a turno Aprobado.
- 11. El sistema realizar el cambio de turno y se notifica al empleado por correo.AN01
- 12. El administrador selecciona el botón “Guardar”
- 13. El sistema guarda en bitácora las acciones realizas. AN03
- 14. Fin del caso de uso.


### 3.4. Flujos Alternos

#### [FA01]: Validación de Credenciales

- 1. El sistema valida que las credencias no son correctas.
- 2. El sistema muestra un mensaje de error “Credenciales incorrectas”
- 3. El sistema retorna al paso 1 del FB.


#### [FA02]: Opción Rechazar Turno

- 1. El administrador selecciona la opción Rechazar.
- 2. El sistema Rechaza la solicitud y cambia de estado a rechazada administrador
- 3. El sistema notifica al empleado por correo el rechazo de su solicitud. AN02
- 4. Fin del FA


#### [FA03]: Solicitudes Licencias y Vacaciones

- 1. El administrador selecciona la opción Solicitudes Licencias/vacaciones RN01
- 2. El sistema muestra en pantalla una lista de todas las solicitudes de Licencias y solicitudes de vacaciones enviadas por el empleado. AN07
- 3. Para cada solicitud, el administrador tiene las siguientes Opciones:

- a. Aprobar.
- b. Rechazar
- c. Botón “Regresar”


- 4. El administrador selecciona la opción Aprobar. FA04, FA05, RN01, RN02
- 5. El sistema aprueba la solicitud y cambia de estado a Aprobada administrador área y se envía al administrador de RRHH.
- 6. El sistema notifica al empleado por correo electrónico de su aprobación.AN04
- 7. El administrador selecciona el botón “Guardar”
- 8. El sistema guarda en bitácora las acciones realizas. AN03
- 9. Fin del FA


#### [FA04]: Opción Rechazar Licencias

- 1. El administrador selecciona la opción Rechazar.


- 2. El sistema valida que la solicitud no esté siendo procesada por otro administrador. FA05
- 3. El sistema Rechaza la solicitud y cambia de estado a Rechazada administrador área
- 4. El sistema notifica al empleado por correo el rechazo de su solicitud. AN02
- 5. Fin del FA


#### [FA05]: Solicitud en proceso

- 1. El sistema valida que la solicitud ya está siendo procesada por otro administrador
- 2. El sistema bloquea la acción de aprobación o rechazo
- 3. El sistema muestra el mensaje: “Esta solicitud ya está siendo procesada por otro administrador”
- 4. Fin del FA


### 3.5. Postcondiciones

1. El sistema debe enviar un correo electrónico al empleado, notificando el motivo de su inactivación. Ver AN01

### 4. Reglas de negocio

- [RN01]: Administrador

1. Los cambios realizados a las solicitudes enviadas por empleados las aprueba o rechaza el administrador.

- [RN02]: Procesamiento de solicitudes


- 1. El sistema debe impedir que dos administradores procesen simultáneamente la misma solicitud
- 2. Si una solicitud ya está siendo procesada, el sistema mostrará el mensaje: “Esta solicitud ya está siendo procesada por otro administrador”
