- 1. Introducción. un sistema de turnos es una herramienta clave para la gestión eficiente del tiempo y los recursos humanos en cualquier organización, ayudando a garantizar un flujo de trabajo ordenado y productivo.
- 2. Objetivo. Este caso de uso describe el proceso de generación y gestión de la nómina de empleados de la empresa.
- 3. Definición Caso de Uso 3.1. Actores


- 1. Empleado.
- 2. Sistema
- 3.2. Precondiciones


- 1. El empleado debe contar con el RolEmpleado.
- 2. Que el empleado este activo en el sistema.
- 3.3. Flujo Normal Básico


- 1. El empleado ingresa su usuario y contraseña e inicia sesión.
- 2. El sistema valida que las credenciales sean correctas. FA01
- 3. El sistema muestra en pantalla las opciones siguientes: AN01

- a. Gestiones del Empleado
- b. Cambios de Turno
- c. Botón: Salir


- 4. El usuario selecciona la opción Gestiones del Empleado.AN02
- 5. El sistema muestra en pantalla los campos siguientes:


- a. Gestiones:

- i. Vacaciones
- ii. Permiso personal
- iii. Citas al IGSS
- iv. Licencia de cumpleaños
- v. Suspensión Laboral
- vi. Otros


- b. Fecha Inicio


- c. Fecha fin
- d. Motivo de solicitud
- e. Botón Guardar
- f. Botón Regresar


- 6. El empleado elige el tipo de gestión.
- 7. El empleado selecciona la fecha de inicio y fecha fin de su permiso, así como el motivo de la solicitud.

- 8. El empleado selecciona el botón enviar y envía la solicitud al administrador del área con el estado pendiente de aprobación. FA04, FA05, RN02.

- 9. El sistema muestra en pantalla un mensaje “Gestión creada con éxito”
- 10. El sistema guarda en bitácora las acciones realizas.
- 11. Fin del caso de uso.


#### 3.4. Flujos Alternos

##### [FA01]: Validación de Credenciales

- 1. El sistema valida que las credencias no son correctas.
- 2. El sistema muestra un mensaje de error “Credenciales incorrectas”
- 3. El sistema retorna al paso 1 del FB.


##### [FA02]: Opción Cambios de turno

- 1. El empleado selecciona la opción Cambio de turno.
- 2. El sistema muestra un formulario con los campos siguientes:AN03

- a. Fecha Inicial
- b. Turno Inicial
- c. Fecha Nueva
- d. Turno Nuevo
- e. Justificación
- f. Botón “Guardar”
- g. Botón “Limpiar”
- h. Botón “Regresar”


- 3. El empleado ingresa la fecha inicial.
- 4. El empleado ingresa el turno inicial.
- 5. El empleado ingresa la fecha nueva.
- 6. El empleado ingresa el turno nuevo.
- 7. El empleado ingresa en un campo de texto la justificación.

- 8. El empleado selecciona el botón enviar y envía la solicitud al administrador del área con el estado pendiente aprobar turno. FA03, FA04, FA05, RN02

- 9. El sistema muestra en pantalla un mensaje de éxito “cambio de turno solicitado con éxito”
- 10. El sistema registra la solicitud del cambio de turno en base de datos.
- 11. El sistema guarda en bitácora las acciones realizas.
- 12. Fin del FA.


##### [FA04]: Botón Regresar

- 1. El usuario selecciona el botón regresar.
- 2. El sistema regresará a la pantalla principal.
- 3. Fin del FA.


##### [FA05]: Validación de fechas

- 1. El sistema valida que la fecha de inicio no sea menor a la fecha actual
- 2. El sistema valida que la fecha fin no sea menor a la fecha de inicio
- 3. El sistema no permite poner las fechas
- 4. Fin FA


### 3.5. Postcondiciones

- 1. La solicitud debe quedar registrada en el sistema con estado pendiente de aprobación
- 2. El sistema debe almacenar las fechas y motivo de la solicitud.
- 3. El sistema debe registrar en bitácora las acciones realizadas por el empleado


#### 4. Reglas de negocio

- [RN01]: Aprobación de solicitud

1. La solicitud de Licencias y vacaciones solo lo puede realizar el empleado, siempre y cuando cuente con días de vacaciones.

- [RN02]: Validación de fechas


- 1. La fecha de inicio de cualquier solicitud no puede ser menor a la fecha actual.
- 2. La fecha fin no puede ser menor a la fecha de inicio de la solicitud
