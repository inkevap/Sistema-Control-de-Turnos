- 1. Introducción. un sistema de turnos es una herramienta clave para la gestión eficiente del tiempo y los recursos humanos en cualquier organización, ayudando a garantizar un flujo de trabajo ordenado y productivo.
- 2. Objetivo. Facilitar la asignación de turnos individuales a los empleados, considerando las horas trabajadas de los empleados y teniendo un control con las necesidades operativas de la empresa.
- 3. Definición Caso de Uso 3.1. Actores


- 1. Administrador Area
- 2. Sistema
- 3.2. Precondiciones


- 1. Que el administrador cuente con el Rol:AdminArea.
- 2. Que existan empleados registrados en el sistema.
- 3. Que la información de la disponibilidad de los empleados esté disponible y actualizada en el sistema.


### 3.3. Flujo Normal Básico

- 1. El administrador ingresa su usuario y contraseña.
- 2. El sistema valida que las credenciales sean correctas. FA01
- 3. El administrador ingresa al módulo de asignación de turnos en el sistema.
- 4. El administrador selecciona la opción para asignar turnos.
- 5. El sistema muestra en pantalla los siguientes campos:


- a. Fecha Inicio
- b. Fecha Fin
- c. Empleados (combo box)
- d. Turno (Combo box)

- i. Turno Matutino
- ii. Turno Vespertino
- iii. Turno Diurno


- e. Supervisor (Combo box)
- f. Botón “Asignar”


#### g. Botón “Regresar”

- 6. El administrador selecciona del combo box al empleado al que se le asignará el turno.
- 7. El administrador selecciona la fecha de inicio y fecha fin para asignar el turno.

- 8. El administrador selecciona el turno nuevo que se va a asignar

- 9. El administrador selecciona al supervisor de turno que se le va a asiganar al empleado
- 10. El administrador selecciona el botón “Guardar”. FA02

- 11. El sistema valida:

- a) Que la asignación del turno cumpla con los horarios laborales establecidos. RN02
- b) Que el empleado pertenezca al supervisor del administrador del área. RN03
- c) Que el supervisor seleccionado pertenezca a la misma área del empleado. RN04
- d) Que el supervisor seleccionado corresponda al turno asignado. RN04


- 12. El sistema guarda el turno asignado al empleado.
- 13. El sistema muestra en pantalla un mensaje “Asignación creada con éxito”
- 14. El sistema guarda en bitácora las acciones realizas.
- 15. Fin del caso de uso.


### 3.4. Flujos Alternos

- [FA01]: Validación de Credenciales

- 1. El sistema valida que las credencias no son correctas.
- 2. El sistema muestra un mensaje de error “Credenciales incorrectas”
- 3. El sistema retorna al paso 1 del FB.


- [FA02]: Botón Regresar


- 1. El usuario selecciona el botón regresar.
- 2. El sistema regresará a la pantalla principal.
- 3. Fin del FA.


### 3.5. Postcondiciones

- 1. Que el turno y supervisor hayan sido asignados correctamente al empleado y registrados en el sistema.


- 2. Que los empleados puedan visualizar sus nuevos turnos asignados
- 3. Que el sistema registre en bitácora las asignaciones realizadas.


### 4. Reglas de negocio

- [RN01]: Rol administrador

1. Los cambios de turno solo los modificar el administrador, si los turnos perjudican los horarios de los empleados.

- [RN02]: Horas Laborales

- 1. El administrador solo puede asignarle un turno de 8 horas a cada empleado.
- 2. Los turnos que el administrador puede asignar son:


- a. Turno Matutino
- b. Turno Vespertino
- c. Turno Nocturno


- [RN03]: Asignación por supervisor

1. El Admin Área solo puede asignar turnos a los empleados que lo tengan como supervisor

- [RN04]: Validación de supervisor


- 1. El supervisor asignado debe pertenecer a la misma área del empleado
- 2. El supervisor asignado debe corresponder al turno seleccionado para el empleado.
