- 1. Introducción. un sistema de turnos es una herramienta clave para la gestión eficiente del tiempo y los recursos humanos en cualquier organización, ayudando a garantizar un flujo de trabajo ordenado y productivo.
- 2. Objetivo. Este caso de uso permite el marcaje de los empleados para un mejor control en la empresa.
- 3. Definición Caso de Uso


### 3.1. Actores

- 1. Administrador del área
- 2. Empleado
- 3. Sistema


### 3.2. Precondiciones

- 1. Que el administrador cuente con el RolAdminArea.
- 2. Que el empleado cuente con el RolEmpleado.
- 3.3. Flujo Normal Básico


- 1. El usuario ingresa su usuario y contraseña e inicia sesión.
- 2. El sistema valida que las credenciales sean correctas. FA01
- 3. El usuario ingresa a la opción marcaje.
- 4. El sistema muestra en pantalla las opciones siguientes.

- a. Timer
- b. Marcar Entrada
- c. Marcar Primer descanso
- d. Marcar Segundo descanso
- e. Marcar salida
- f. Información del Marcaje
- g. Botón: Regresar


- 5. El usuario selecciona la opción Entrada. FA03, FA04,FA07, RN01
- 6. El sistema valida la hora de entrada del usuario. FA02
- 7. El sistema muestra en pantalla un mensaje “Marcaje realizado con éxito”.
- 8. El sistema guarda en bitácora las acciones realizas. AN01


- 9. Fin del caso de uso.


### 3.4. Flujos Alternos

#### [FA01]: Validación de Credenciales

- 1. El sistema valida que las credencias no son correctas.
- 2. El sistema muestra un mensaje de error “Credenciales incorrectas”
- 3. El sistema retorna al paso 1 del FB.


#### [FA02]: Validación entrada tarde

- 1. El sistema valida que la entrada se haya realizado después de las 8:00 am.
- 2. Fin del FA.


#### [FA03]: Marcaje primer Descanso

- 1. El usuario selecciona la opción marcar descanso
- 2. El sistema valida que se haya marcado la entrada. FA05
- 3. El sistema regresa al paso 7 del FB


#### [FA04]: Marcaje segundo Descanso

- 1. El usuario selecciona la opción marcar descanso
- 2. El sistema valida que se haya marcado el primer descanso. FA06
- 3. El sistema regresa al paso 7 del FB


#### [FA05]: Mensaje de alerta Primer descanso

- 1. El sistema valida que el usuario aun no ha marcado la entrada
- 2. El sistema muestra en pantalla un mensaje:” Debe marcar la entrada antes de registrar el descanso.”
- 3. El sistema regresa al paso 5 del FB.


#### [FA06]: Mensaje de alerta segundo descanso

- 1. El sistema valida que el usuario aún no ha marcado el segundo descanso.
- 2. El sistema muestra en pantalla un mensaje:” Debe marcar el primer descanso antes de registrar el segundo descanso.”
- 3. El sistema regresa al paso 5 del FB.


#### [FA07]: Marcar salida

- 1. El usuario selecciona marcar salida.
- 2. El sistema valida que se hayan marcado los descansos.FA08,FA09
- 3. El sistema regresa al paso 7 del FB .


#### [FA08]: Mensaje de alerta Salida

- 1. El sistema valida que el usuario aún no ha marcado el primer descanso.
- 2. El sistema muestra en pantalla un mensaje cuando no se ha marcado el primer descanso:” Debe marcar el primer descanso antes de registrar la salida.”
- 3. El sistema regresa al FA03.


#### [FA09]: segundo mensaje de alerta Salida

- 1. El sistema valida que el usuario aún no ha marcado el segundo descanso.


- 2. El sistema muestra en pantalla un mensaje cuando no se ha marcado el segundo descanso: ”Debe marcar el segundo descanso antes de registrar la salida.”
- 3. El sistema regresa al FA04.


#### [FA10]: Marcaje repetido

- 1. El sistema valida que el usuario ya realizó el mismo marcaje en la jornada actual.
- 2. El sistema bloquea el nuevo registro.
- 3. El sistema muestra el mensaje: “No puede repetir el mismo marcaje”.
- 4. El sistema regresa al paso 5 del FB.


#### [FA03]: Información del Marcaje

- 1. El usuario selecciona la opción Información del marcaje
- 2. El sistema muestra en pantalla la información de los marcajes realizados.
- 3. El usuario selecciona el botón regresar.
- 4. El sistema regresa a la pantalla principal.

- 3.6. N/A


### 4. Reglas de negocio

- [RN01]: marcaje de entrada

El marcaje de entrada se debe validar que el usuario lo puede realizar antes de la 8:00 am o a las 8:00 am, pasando las 8:01 am ya es una entrada tarde.

- [RN02]: Marcajes duplicados


- 1. El sistema no debe permitir registrar el mismo tipo de marcaje más de una vez dentro de la misma jornada laboral.
- 2. Si el usuario intenta repetir un marcaje, el sistema mostrará el mensaje: “No puede repetir el mismo marcaje”.
